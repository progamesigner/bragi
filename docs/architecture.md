# 架構與資料生命週期

Bragi 的工作區跨畫面保留稿件，音訊則由同一個控制器管理。重新整理後只可恢復本機文字暫存；圖片、編輯歷史、播放位置與音訊都不是持久資料。

## 程式分工

| 位置 | 職責 |
|---|---|
| `src/routes/index.tsx`、`review.tsx`、`play.tsx`、`finished.tsx` | 取圖、校對、朗讀與完成頁，依工作區狀態限制進入 |
| `src/lib/app-controller.ts` | 登入、辨識、匯入／匯出、取代確認、清除與草稿恢復 |
| `src/lib/store/workspace.ts` | 圖片、文字、編輯歷史、匯出基準、目前段落與已播放紀錄 |
| `src/lib/store/preferences.ts`、`persist.ts` | 裝置偏好、套用時機與容錯儲存 |
| `src/lib/autosave.ts`、`draft.ts` | 草稿暫存與版本化 JSON 驗證 |
| `src/lib/audio/controller.ts`、`session.ts` | 主朗讀、段落試聽、聲音試聽的播放意圖與資源生命週期 |
| `src/lib/speech-cache.ts`、`speech-stream.ts` | WAV 快取、共享合成請求、PCM 串流與播放 |
| `src/lib/server/*`、`src/routes/api/*` | 認證、供應商請求、驗證、錯誤與日誌 |
| `src/lib/i18n/*` | 7 種介面語言與逐鍵 fallback |

沒有草稿時，校對、朗讀及完成頁會導回取圖；稿件不能朗讀時導回校對。完成頁要求末段有有效播放紀錄，並不要求每段都播過，因此會區分全部播放與部分播放。

## 草稿與編輯

本機 key 為 `bragi:autosave:v1`，停止編輯約 1,000 ms 後寫入 localStorage。登入後由使用者選擇恢復，不覆寫現有工作區，也不呼叫 Gemini。無效暫存會嘗試刪除；儲存存取失敗不阻止編輯。

暫存與匯出共用 `bragi-draft` version 1 格式，只含辨識語言、故事類型與段落的 ID、文字、語氣、可選朗讀修正。圖片、音訊、偏好、登入資料與編輯歷史都不在其中。清除、登出或捨棄暫存會刪除本機副本；顯示與聲音偏好另行保存。

| 限制 | 值 |
|---|---|
| JSON 檔案與正規化匯出大小 | 200,000 UTF-8 bytes |
| 段落數 | 50 |
| 口白、發音修正 | 各 10,000 字素 |
| 語氣／故事類型／語言／ID | 120／80／35／64 字素 |

編輯、匯入與匯出使用同一份草稿限制。超限編輯在改動工作區前拒絕；匯入會驗證完整 payload 及正規化匯出大小，拒絕未知版本、重複 ID 與多餘欄位。匯入的長段落仍可能需要拆分才能朗讀。

發音修正優先於原口白作為合成文字；試聽、預取、串流、WAV 與快取都使用相同規則。拆分有修正的段落會丟棄修正；合併則合併兩段實際朗讀文字。原口白與實際朗讀文字都必須通過播放長度檢查。

輸入欄編輯時先保留瀏覽器原生 undo，失焦或結構編輯時建立工作區歷史節點。復原／重做不跨草稿取代。匯出會更新已保存基準；OCR 與本機恢復的草稿在匯出前仍視為未匯出。本機暫存不是對外備份。

取代確認期間，已驗證的新候選資料先放在一旁，使用者接受後才套用。取消的操作與過時請求不會覆蓋現有稿件。「先匯出」只觸發下載，之後要使用者另外按確認，才會執行會丟失內容的動作。

## 音訊路徑

`AudioController` 在第一次非同步等待之前就取得播放控制並停止前一個聲音，這樣使用者點擊的手勢在播放時仍然有效。主朗讀、段落試聽與聲音試聽共用這個控制器，過時的請求不會在之後才發出聲音。播放被瀏覽器擋下時，已生成的音訊會保留，下一次點擊直接重試播放。離開朗讀會取消請求、停止音訊來源，並釋放音訊 URL 與 Wake Lock。

- 1× 且沒有完整快取時，可由 `/api/tts-stream` 取得 PCM，以 Web Audio 邊收邊播。傳輸邊界切開的 sample 會保留到下一塊。
- 完成串流後重組 WAV，供重播、快取與 seek。播放中的 PCM 不會只因 WAV 備妥而自動切換；明確 seek 才切到完整音訊。
- 非 1× 使用完整 WAV 與原生 `preservesPitch`。試聽與預取也走 `/api/tts`。主朗讀在 1× 且沒有完整音訊時走串流；如果那一段的預取還在進行，就等待並沿用那個預取，不另外開串流。
- 每段結束都停下。選擇前後段不會觸發合成，最多只預取下一段。改聲音或語速時，只取消設定已經不符的預取；只差語速的預取共用同一次合成。暫停與中斷會保留位置，恢復時沿用當次的聲音與語速，新的播放才使用新設定。
- seek 需要完整音訊與有效長度；暫停時 seek 保持暫停。鎖屏或切 App 後不保證背景播放，真機待驗項目見 [驗收清單](reading-device-checklist.md)。

WAV 快取上限為 3 筆或 9,000,000 bytes，依最近使用順序淘汰。key 含實際朗讀文字、語氣、故事類型與聲音；速度由播放控制器另外納入準備狀態。同內容並行的完整音訊請求共享合成，各呼叫者可獨立取消，全部離開才取消上游。完全取消後不寫入快取，新請求會重新合成。更換圖片、清除或登出時清掉快取。聲音試聽的固定句不進入故事朗讀快取。

## 顯示與可及性

字級、主題、語言與常亮選項立即套用；聲音與速度由每次播放動作讀取快照。Wake Lock 需使用者啟用，回到可見頁面時嘗試重取，離開朗讀即釋放。

進度、成功與錯誤使用不同 live-region 語意，錯誤保留 request ID。校對與朗讀切換管理焦點；欄位錯誤提供指引，控制項有可見焦點。繁體中文是來源字典，其他語言逐鍵 fallback；OCR 內容、語氣、試聽句與草稿不翻譯。用語審查狀態見 [i18n glossary](i18n-glossary.md)。

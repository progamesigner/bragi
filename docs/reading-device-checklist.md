# 朗讀真機驗收

iOS Safari 與 Android Chrome 各執行一次；一般 HTTPS 分頁及已安裝 PWA 分別記錄手機、OS、瀏覽器版本與結果。以下是待執行步驟，不代表已通過。

1. 匯入兩段稿件。分別在完整 WAV 快取、下一段預取完成、未快取 1× PCM、未快取非 1× WAV 路徑點一次「播放此段」。等合成完成，不再觸碰頁面：應播放且每段結束停下；非 1× 等整段完成且音高正常。
2. 若播放被阻擋，點「點一下播放」：應沿用已生成音訊，不再合成。暫停再繼續應從原位置播放。
3. 完整 WAV 用拖曳與鍵盤方向鍵／Home／End 調整段內 slider：應從指定位置播放，暫停時 seek 仍保持暫停。PCM 未完成時 slider 停用，完成後可操作；記錄第一次切 WAV 的停頓與爆音。
4. 播放與準備中各測鎖屏、切 App、來電後返回：不應自行發聲；繼續播放應保留位置與聲音／速度，無重新合成。若系統終止頁面，另記錄重新載入及暫存恢復。
5. 主朗讀中開設定並試聽，再返回校對試聽、切換另一段試聽：任何時刻只應有一個聲音。關閉設定或離開朗讀後，不應有遲到音訊；離開朗讀釋放 Wake Lock。
6. 暫停主朗讀後修改聲音／速度：朗讀頁應顯示下一次播放套用；繼續保持原設定，新播放或重播才套用新設定。非 1× 提示仍可見。
7. 接鍵盤／藍牙翻頁器。Space 播放／暫停，←／→ 只換段並停止聲音；長按不重複。設定開啟、輸入欄或按鈕聚焦時沿用控制本身行為；校對／完成頁不啟動朗讀。
8. 用 VoiceOver／TalkBack 操作主按鈕、取消、段落與 slider，讀取可見稿件及發音修正。錯誤只宣告一次。手機 320px、平板橫向 1180×820：按鈕不隨狀態移位，無水平溢出。
9. 跳過首段，只播末段後完成：顯示「播放了 1 / 2 段」及已播放段落總長。未匯出區塊應在摘要正下方、文字左／匯出右；匯出後消失。新故事須先確認；取消保稿。Back 回朗讀但不自動播放；從頭再唸回首段，返回校對保留稿件。
